# Bonava Limited website

Static site for [bonava.co.ke](https://bonava.co.ke). Plain HTML/CSS/JS, no build step.
Hosted on GitHub Pages from the `main` branch; the `CNAME` file sets the custom domain.

## Preview locally

```bash
python -m http.server 8125
```

Then open http://localhost:8125

## Editing

- Page content: `index.html`
- Styles: `assets/css/style.css`
- Photos: `assets/img/` (sources and licences in `CREDITS.md`)

The quote form has no backend; it opens the visitor's email app addressed to info@bonava.co.ke.
